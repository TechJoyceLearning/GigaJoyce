# GigaJoyce

GigaJoyce is a modular Discord bot developed for the [TechJoyce channel](https://www.youtube.com/@TechJoyce).  
It was created both as a learning project and as a framework that demonstrates how a Discord bot can be structured in a modular way.  
The idea is simple: the **core** provides the stable foundation, while **modules** act as plug-and-play features. Developers can add commands, events, and settings by writing a module without touching the rest of the system.  

The internals of the bot are also fully documented. Every handler, manager, and utility is explained so that contributors can understand the architecture when they want to extend or improve it. The intention is not to force changes to the core, but to provide enough transparency for those who are curious or would like to suggest refinements.  

Contributions are welcome. If you want to add a feature, the recommended way is to create a module. The documentation explains how to do this, and also provides detailed notes on the underlying framework for anyone who wants to dive deeper.  

You can read the full documentation here:  
👉 [GigaJoyce Docs](https://techjoycelearning.github.io/GigaJoyce/)
